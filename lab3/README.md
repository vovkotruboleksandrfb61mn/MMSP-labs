## Мета

Опанувати мережі Петрі як формалізм моделювання взаємодіючих процесів:
проаналізувати задану мережу та синтезувати власну модель за умовою.

## Завдання

**Аналіз.** Побудувати граф досяжних розміток для мережі варіанта 3
(позиції $p_1 \dots p_4$, початкова розмітка $\mu_0 = (2, 0, 1, 0)$).

**Синтез.** Задача 3 — перетворення задачі про обідаючих філософів для
випадку, коли виделки беруть по черзі, а за стіл запрошують філософа так, щоб
це не перешкоджало загальному поглинанню їжі.

## Результати

**Аналіз мережі варіанта 3:** 7 досяжних розміток, 11 дуг, тупикових розміток
немає. Межі позицій — $p_1 \le 3$, $p_2 \le 6$, $p_3 \le 2$, $p_4 \le 2$, тобто
мережа 6-обмежена й не є безпечною. Знайдено два P-інваріанти:
$2p_1 + p_2 + 4p_3 = 8$ і $2p_1 - p_2 + 4p_4 = 4$.

**Синтез.** Модель будується трьома кроками, щоб було видно саме перетворення:

| Модель | $n = 3$ (розміток / дуг / тупиків) | $n = 5$ |
|--------|-----------------------------------|---------|
| Задача 1 — обидві виделки одночасно | 4 / 6 / 0 | 11 / 30 / 0 |
| Задача 2 — виделки по черзі | 14 / 27 / **1** | 82 / 265 / **1** |
| Задача 3 — із запрошеннями | 13 / 24 / **0** | 81 / 260 / **0** |

## Основні висновки

- **Семафор прибирає рівно одну розмітку — і це саме тупикова.** Перехід від
  задачі 2 до задачі 3 змінює простір станів із 14 розміток на 13 (і з 82 на 81
  при п'яти філософах). Тупик задачі 2 — стан, у якому кожен філософ тримає
  ліву виделку, а всі виделки зайняті.
- **Запрошень має бути $n - 1$, а не одне.** Читання «запрошують одного»
  буквально лишило б за столом рівно одного їдця, що суперечить тій самій
  фразі умови — «не перешкоджає загальному поглинанню їжі обідаючими». Крім
  того, формулювання задачі 4 («запрошення необов'язкові») показує, що в
  задачі 3 запрошення є обов'язковим механізмом доступу.
- **Інваріанти й перебір доводять різне.** P-інваріанти дають **структурний**
  доказ обмеженості, незалежний від перебору, але лише $p_2 \le 8$. Тісніша
  межа $p_2 \le 6$ походить саме з вичерпного обходу: розмітка $(0, 8, 0, 3)$
  задовольняє обидва рівняння інваріантів, але недосяжна. Натомість
  відсутність тупиків доведена остаточно — саме тому, що граф скінченний і
  побудований повністю.
- Графи досяжності показано для трьох філософів: при п'яти вони мають 82 і 81
  вершину й нечитабельні на сторінці; відповідні числа наведено таблицею.
